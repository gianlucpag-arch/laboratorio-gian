# PARTE 2 – PROMPTS E FLUXO PARA REPLICAR

*Trechos entre aspas são falas do vídeo; o resto é reconstrução. Ajuste ao seu caso.*

## 2.1 Criar o personagem no ChatGPT (reconstrução)

```
Anexei (1) a referência do personagem base e (2) a referência do que quero modificar. Resumo: [descrição curta do que quero]. Crie o personagem em estilo [realista, engraçado, bizarro]. Gere 2 variações mais realistas e me dê o prompt usado para cada uma. Depois eu peço ajustes.
```

## 2.2 Frame inicial com os personagens certos (reconstrução)

```
Anexei o frame do vídeo original, o personagem principal e um personagem secundário ([nome], versão realista). Recrie esse frame com os personagens certos, mantendo a mesma pose/orientação do personagem original e mudando a cena conforme necessário. Dê também o prompt para gerar essa imagem no Google Flow.
```

## 2.3 Pedir ao ChatGPT o prompt de substituição (baseado no que foi dito)

```
Vou adicionar o vídeo no Google [Flow/Omni] como referência, mais a cena, mais o character sheet anexados. Quero um prompt para trocar totalmente o homem do vídeo pelo [personagem]. O vídeo tem 10 segundos. Quero apenas trocar o personagem, mantendo exatamente o mesmo movimento (motion control).
```

(O autor usou o prompt genérico devolvido, que apenas manda **trocar o personagem**, em todas as cenas. Ele começa com "replace".)

## 2.4 Passo a passo no Google Flow

1. Cortar o vídeo original em clipes de **até 10 s**.
2. Configurar **9:16**.
3. Subir as referências, nesta ordem: **(1) o vídeo**, **(2) character sheet do novo personagem**, **(3) referência da cena** (inclui personagens secundários).
4. Colar o prompt de substituição ("replace") e gerar (cerca de **20 créditos** por geração).
5. Baixar (720p grátis; 1080p com plano) e **juntar no CapCut**; ajustar as emendas na edição.

## 2.5 Checklist de análise de campanha de RPM

- [ ] Li o brief e o contrato (ou pedi prós e contras ao ChatGPT).
- [ ] Há exclusividade? O personagem/conta fica com a empresa? Preciso dar acesso à conta?
- [ ] A campanha obriga uma ferramenta paga? Quanto custa cada vídeo?
- [ ] Qual o mínimo de views para empatar o custo?
- [ ] Regras de conta (idade mínima por país, checklist).
- [ ] Sou elegível? (O autor não era, por não assinar a ferramenta.)
